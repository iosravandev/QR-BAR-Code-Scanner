# QR & BAR Code Scanner

Тестовое приложение для сканирования штрих-кодов и QR-кодов. Поддерживает получение информации о товарах через OpenFoodFacts, сохранение результатов в локальную базу и просмотр истории.

## ⚙️ Технологии
- Swift, SwiftUI + (немного UIKit при работе с камерой)
- AVFoundation (камера, фонарик)
- URLSession (+ Swift Concurrency: async/await)
- Combine (состояние/события)
- Core Data (кэш/история)
- Архитектура MVVM

---

## ✨ Возможности
- 📸 Сканирование QR и штрих-кодов (реал-тайм), рамка зоны сканирования
- 🔦 Включение/выключение фонарика
- 🔐 Запрос разрешений на камеру, алерты при ошибках/запрете
- 🌐 Поиск данных о продукте по штрих-коду в OpenFoodFacts  
  `https://world.openfoodfacts.org/api/v0/product/{barcode}.json`
- 🧾 Для QR-кодов — показ содержимого (ссылка открывается по тапу)
- 💾 Сохранение результата в Core Data (без дублей), переименование записи
- 📋 Список всех сканов (название/тип/дата)
- 🔎 Экран деталей: название, бренд, ингредиенты, Nutri-Score (если есть) / содержимое
- 📤 Share Sheet для публикации/отправки результата
- 🌓 Светлая/тёмная тема, базовая HIG-верстка
