# QR & BAR Code Scanner

Простое приложение для сканирования QR и штрих-кодов на iOS, написанное на Swift с использованием SwiftUI и UIKit.

## Возможности
- Сканирование QR и BAR-кодов в реальном времени  
- Сохранение истории сканов  
- Получение информации о продуктах через OpenFoodFacts API  
- Поддержка светлой и тёмной темы  
- Управление фонариком  
- Поделиться результатом сканирования  

## Используемые технологии
- Swift  
- SwiftUI / UIKit  
- Core Data  
- AVFoundation  
- URLSession  
- MVVM архитектура
